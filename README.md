# clipvolume

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-blue.svg)](LICENSE)
[![Website](https://img.shields.io/badge/site-clipvolume.com-5f918e.svg)](https://clipvolume.com)

**Who's making that noise?** A macOS menu bar volume control with the per-app
mixer Apple never shipped.

- Click the speaker → **master volume**, mute, output-device picker.
- Click **Mixer ›** → every app currently producing audio, each with a **live
  level meter**, its own **slider** (relative to master), and a **mute** button.
- **Play/pause** Spotify, Music, TV, QuickTime Player and VLC directly — even
  Spotify playing on another device via Spotify Connect.
- Per-app settings live as long as that app does; relaunch it and it's back at 100%.
- **No virtual audio driver, no kernel extension, no Accessibility permission.**
  Built on Core Audio process taps.
- Lives in the menu bar (no Dock icon). Can launch at login.

Website: **[clipvolume.com](https://clipvolume.com)** · Current version: **0.1.0**

---

## Install

**Easiest:** download the notarized `clipvolume.dmg` from the
[Releases page](https://github.com/mrmichaelmoorecom-sys/clipvolume/releases),
open it, and drag **clipvolume** onto **Applications**. Release builds are signed
with a Developer ID and notarized by Apple, so they open with no Gatekeeper warning.

Requires **macOS 14.4** or later (that's when process taps got their own permission).

## Permissions

| Feature | Mechanism | Permission |
|---|---|---|
| Master volume / mute / device picker | Core Audio HAL device properties | none |
| "Which app is making noise" list | `kAudioHardwarePropertyProcessObjectList` + `IsRunningOutput` | none |
| Level meters | Core Audio **process tap** (unmuted) per playing app, only while the mixer is open | **System Audio Recording** (one prompt) |
| Per-app volume / mute | process tap with `.muted` + the app's audio played back by clipvolume at the chosen gain | same grant |
| Play/pause | Apple Events via `osascript` to Spotify / Music / TV / QuickTime / VLC | **Automation** (one prompt per app) |

Apps you haven't touched are never routed through clipvolume. Nothing is recorded,
nothing is written to disk, and the app makes no network connections.
Browsers can't be paused from outside (Chrome/Safari only accept JavaScript
injection, and only if the user turns that on), so a YouTube tab gets mute, not pause.

## Build from source

Requires Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
brew install xcodegen librsvg   # once
make run                        # generate project, debug build, launch
```

`make project` writes `clipvolume.xcodeproj` from `project.yml`; open that in Xcode
if you prefer. Debug builds are signed with the same Developer ID as releases so
the TCC grants persist between builds.

## Release pipeline

One-time: create an app-specific password at appleid.apple.com, then

```sh
xcrun notarytool store-credentials clipvolume-notary --apple-id you@example.com --team-id HA5AB7JS87
```

Then:

```sh
make app        # Release archive → Developer ID export → build/export/clipvolume.app
make dmg        # + drag-to-Applications dmg (signed, not yet notarized)
make notarize   # notarize + staple the app, rebuild the dmg, notarize + staple it
make release    # + tag v<version> and publish a GitHub release with the dmg attached
make icons      # regenerate AppIcon.icns, favicon, og-image and dmg background from img/appicon.svg
```

## How the mixer works

macOS has no per-app volume API. Since macOS 14.2, Core Audio can create a
**process tap** on another process's audio. clipvolume uses that in two modes:

- **monitor** — an unmuted tap, read-only, just to draw the level meter. Created
  for every playing app while the mixer is open; torn down when the panel closes.
- **control** — a tap with `muteBehavior = .muted`, which silences the app at the
  output device, plus a private aggregate device (tap + output device) whose
  IO callback copies the tapped audio to the output scaled by the slider (or
  zeroed while muted). Created only for apps you've adjusted, and kept alive
  while the panel is closed so a muted app stays muted.

Taps are per process object, so `AppResolver` groups helper processes under the
responsible app (Chrome's audio helper → Google Chrome, `com.apple.WebKit.GPU` →
Safari) and one tap covers all of them. On macOS 26 the tap is also asked to
restore itself by bundle ID if a helper is relaunched.
